기능

파일 요약 — 변경 파일마다 한 줄. 뭘 바꿨는지와 그게 틀리면 뭐가 깨지는지를 같이 쓴다. 옆의 표시는 틀렸을 때 번지는 범위다(중요·보통·훑기). GitHub은 파일을 경로순으로 늘어놓아서 위험한 파일이 맨 아래 깔리는데, 목록만 훑어도 어디부터 볼지 정해진다.

▸ src/api/client.ts
● 중요 토큰 갱신을 인터셉터로 옮겼다. 갱신이 실패했는데 원래 요청을 다시 보내면 무한 재시도가 된다.

메모 — 줄에 마우스를 올리면 버튼이 뜬다. 눌러서 쓰면 그 줄에 카드가 붙고, 답과 되물음이 같은 카드에 쌓인다. 남한테 보이는 건 GitHub 코멘트를 쓰면 되고, 이건 나랑 클로드 사이라 아무도 안 본다.

구조

확장이 클로드와 직접 통신하지는 않는다. 사이에 로컬 파일과 터미널이 있다.

브라우저(확장)  ──저장──▶  ~/.diffmate/<레포>/<PR번호>.json
                                    │  ▲
                                    ▼  │  CLI로 읽고 쓴다
                          터미널의 Claude Code
                          "파일 요약 채워줘" / "메모 답변 달아줘"
  1. 요약 채우기 — PR을 올린 뒤 터미널에서 Claude Code에게 시킨다. 파일마다 한 줄이 json에 들어가고, 브라우저를 열면 붙어 있다.
  2. 메모 쓰기 — 브라우저에서 쓰면 같은 json에 저장된다.
  3. 답 받기 — 터미널로 가서 "메모 답변 달아줘"라고 한다. 답이 json에 들어가고 브라우저 카드에 뜬다. 새로고침은 필요 없다(3초마다 다시 읽는다).
