파일 위 한 줄은 읽기 시작하기 전에 에이전트가 써 둔 것이다. 카드는 대화다 — 묻고, 답이 오고, 다시 되묻는다.

어떻게 도나

  1. 에이전트가 먼저 쓴다. PR을 올린 직후 파일마다 한 줄을 채운다. 무엇이 바뀌었는지가 아니라, 틀렸을 때 무엇이 깨지는지를 쓴다.
  2. 읽다가 묻는다. 줄에 마우스를 올리면 버튼이 뜬다. 누르고 쓰면 내 컴퓨터의 JSON 파일에 저장된다.
  3. 같은 자리에 답이 온다. 되물으면 같은 카드에 쌓인다. 대화가 코드 옆을 떠나지 않는다.

설치

git clone https://github.com/chaeeun037/diffmate.git
cd diffmate
npm start          # 로컬 데몬 127.0.0.1:7777

그다음 크롬에서 chrome://extensions → 개발자 모드 → 압축해제된 확장 프로그램을 로드 → extension/ 선택. Node 18 이상이면 되고 의존성은 없다.
