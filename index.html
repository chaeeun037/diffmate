diffmate

Open a pull request and every changed file already carries one line telling you why it matters.

When that is not enough, ask Claude right there — the answer lands next to the same line. Nothing is posted to GitHub.

One line per file

Skimming the file list is enough to decide where to start. Every line under a filename is drawn by the extension.

▸ src/lib/retryFetch.ts
● high Retry wrapper every API call goes through. If the stop condition is wrong, a failed request repeats until the tab is closed.
▸ src/pages/_document.tsx
● high Beacon injected into every page. If the path check on the first line is wrong, unrelated pages fire the log too.
▸ src/hooks/useSession.ts
● medium Hook that reads the session. The value is undefined on first render, so branching on it flashes the logged-out screen.
▸ src/constants/LogType.ts
○ skim Registers three log names.

It never says what changed — the diff already shows that. It says what breaks if this is wrong, ranked by how far the damage spreads.

Why this exists

Reviewing AI-written code from a diff alone, you cannot tell which file matters. Files are listed by path, so a one-line constant sits next to something that touches every page. Write it up in the pull request description and it ends up far above the fold, where nobody scrolls back to.

So the explanation moved next to the code. The map is in place before you start reading.

This is not a replacement for GitHub comments. Anything other people should see belongs there. These are yours alone, and the one answering is your AI rather than a colleague — which makes "wait, why is this like this?" an easy thing to ask.

Three steps

  1. Claude goes first. Right after the pull request opens, it fills in one line per file. By the time you open the page it is already there.
  2. Ask as you read. Hover a line, click the button, type. Notes are saved to a file on your machine and nowhere else.
  3. Answers land in place. Ask Claude to answer your notes and they appear on the cards — no refresh needed.

Install

git clone https://github.com/chaeeun037/diffmate.git
cd diffmate
npm start          # local daemon on 127.0.0.1:7777

Then in Chrome: chrome://extensions → Developer mode → Load unpacked → pick extension/. Node 18+, no dependencies.
