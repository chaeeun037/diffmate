diffmate

Leave private notes on a GitHub pull request diff, and have an AI agent answer them in place.

Nothing is posted to GitHub. Notes live on your machine only.

Why a while loop instead of recursion? Doesn't this block the caller?
It does not block — every attempt awaits, so the loop yields between tries. Recursion would grow the stack by one frame per retry, and the stack trace on failure would bury the original error.
Got it. So MAX_ATTEMPTS is the only thing stopping it?
Yes, plus the abort signal passed in init. If neither is set, the loop is bounded only by MAX_ATTEMPTS.

The label above the file is written by the agent before you start reading. The card is a thread: you ask, the agent answers, you push back.

How it works

  1. The agent goes first. Right after opening a PR it writes one line per file — not what changed, but what breaks if it is wrong.
  2. You read the diff and ask. Hover a line, click the button, type. Notes are saved to a JSON file on your machine.
  3. The agent answers in place. Answers land on the same line. Follow-ups stack on the same card, so the thread stays where the code is.

Install

git clone https://github.com/chaeeun037/diffmate.git
cd diffmate
npm start          # local daemon on 127.0.0.1:7777

Then in Chrome: chrome://extensions → Developer mode → Load unpacked → pick extension/. Node 18+, no dependencies.
