diffmate

A Chrome extension that puts one line on every file of a GitHub pull request, and answers the notes you leave on a line through Claude Code.

It drives the Claude Code you already run. Everything stays on your machine, and nothing is posted to GitHub.

Features

File summaries — one line per changed file. It says what you changed and what breaks if it is wrong. The marker beside it is how far the damage spreads (high, medium, skim). GitHub lists files by path, so the risky one often sits at the very bottom; skimming the list is enough to decide where to start.

▸ src/api/client.ts
● high Moved token refresh into the interceptor. If refresh fails and the original request is sent again, it retries forever.

Notes — hover a line and a button appears. Click it, type, and a card attaches to that line; answers and follow-ups stack on the same card. Anything other people should see belongs in a GitHub comment — this one is between you and Claude, and nobody else sees it.

How it works

The extension never talks to Claude directly. A local file and your terminal sit in between.

Browser (extension)  ──writes──▶  ~/.diffmate/<repo>/<pr>.json
                                        │  ▲
                                        ▼  │  read and written through the CLI
                              Claude Code in your terminal
                              "fill in the file summaries" / "answer my notes"
  1. Fill the summaries — right after opening the pull request, ask Claude Code in your terminal. One line per file goes into the json, and it is already there when you open the browser.
  2. Leave notes — written in the browser, saved to the same json.
  3. Get answers — go back to the terminal and say "answer my notes". The answers go into the json and show up on the cards. No refresh needed — it re-reads every three seconds.
